# 17. mai Flags Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** From 1 to 17 May, every 3D bus, coach and tram model flies two gently fluttering Norwegian flags from its front corners.

**Architecture:**

- A new season, `17mai`, has no stop decorations.
- The flags are a mesh per flagged mode, in the model's own space, drawn by a separate `flagLayers` builder that shares the models' transforms.
- The flutter is a deck.gl `LayerExtension`, `FlutterExtension`. It displaces the cloth's vertices by a per-vehicle phase and by `time`/`amount` uniforms.
- The Christmas `TwinkleClock` becomes the season-neutral `AnimationClock`. It drives the flutter, so a tick rebuilds only the flag layers.

**Tech Stack:** TypeScript, React 19, MapLibre GL 6, deck.gl 9.4 (`LayerExtension`, `SimpleMeshLayer`), Vitest (node, `src/**/*.test.ts`), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-21-17-mai-flags-design.md` (builds on `2026-10-20-christmas-trees-design.md`). Read both.

## Global Constraints

- Window 1–17 May inclusive, judged by the date in Europe/Oslo. `?season=17mai` forces it on and `?season=none` forces it off.
- Flags go only on the `BUS`, `COACH` and `TRAM` models that have a usable bearing, wherever the models are drawn. There are none on 2D icons, the ghost, the directionless column or any other mode. The chased vehicle carries flags.
- Two flags per vehicle sit at the front corners, clear of the roof line, so the chase camera behind can see them. They are `FLAG_EXAGGERATION = 3` times a real 30×20 cm flag on a 0.5 m pole. The exaggeration is one constant, and a test holds it equal to `STOP_POLE_EXAGGERATION`.
- Colours: red `#BA0C2F`, white, blue `#00205B`. The Nordic cross runs 6:1:2:1:12 horizontally and 6:1:2:1:6 vertically, with the canton at the pole. These are fixed vertex colours under a white `getColor` and `MODEL_MATERIALS[scheme].shaded`. They are not lamps.
- Flutter: gentle, never flapping, each vehicle on its own phase (a hash of `vehicleId`), streaming back along model −y. It is still under reduced motion, and settles after 60 s idle, waking with the same eases as the Christmas lights.
- A tick only changes uniforms on the flag layers. It never re-creates body, sign, details, lamp or pool layers, and never re-uploads per-vehicle attributes.
- Halloween and Christmas behaviour must not change.
- Testable logic goes in plain `.ts` (Vitest does not collect `.tsx`). Local imports carry `.ts`/`.tsx`. `npm run lint` with zero warnings. Type-check with `npx tsc --noEmit -p tsconfig.app.json`.
- No codespace ids in code comments. Stage by explicit path, never `git add -A` (`build/` and `*.iml` are untracked). Commit messages are plain imperative sentences.
- The current branch `seasonal-pumpkins` tracks `origin/master`. Never push.

## Review Focus

1. **A vehicle with no bearing, or of a non-flagged mode (METRO, RAIL, WATER, unknown), gets flags.** Expected: none. Pinned in Task 5.
2. **A flutter tick re-creates the vehicle model layers.** Expected: only the flag layers change, with the same data and mesh objects. Pinned in Task 5 (`flagLayers` identity) and Task 6 (the flag layers are kept in their own ref).
3. **The season edge in Oslo time.** At 22:30 UTC on 17 May it is already 18 May in Oslo: off. Pinned in Task 1.
4. **17 May breaks the stop-decoration path.** `DECORATIONS` has no `17mai` entry, and the controller or hook must not throw or tick. Pinned in Task 1 (`decorationSpecFor`) and Task 6.
5. **The still pose reads as a flat plate.** Expected: at `amount` 0 the cloth keeps a fixed gentle curve. Pinned in Task 3.

### Task 3: The flutter curve

**Files:** Create `src/domain/flutter.ts`, `src/domain/flutter.test.ts`

**Interfaces:**

- Produces:

  ```ts
  export const FLUTTER_PERIOD_S = 1.6;
  export const FLUTTER_AMPLITUDE = 0.12; // share of cloth length, at the free edge
  export const FLUTTER_WAVES = 1; // wavelengths along the cloth
  export const FLUTTER_STILL = 0.06; // the still pose's curve, share of cloth length
  /** Sideways offset (model x), as a share of the cloth's length, of the point `u` (0 at the pole, 1 at the free edge). */
  export function flutterOffset(
    timeS: number,
    phase: number,
    u: number,
    amount: number,
  ): number;
  ```

  The curve, which the shader in Task 5 must reproduce exactly:

  ```ts
  const travelling = Math.sin(
    2 * Math.PI * (timeS / FLUTTER_PERIOD_S + phase - FLUTTER_WAVES * u),
  );
  return (
    u *
    (FLUTTER_STILL * Math.sin(Math.PI * u) +
      amount * FLUTTER_AMPLITUDE * travelling)
  );
  ```

- [ ] **Step 1: Failing tests:**
  - 0 at the pole (`u` = 0) for any time and amount
  - `|offset| ≤ FLUTTER_STILL + FLUTTER_AMPLITUDE` everywhere
  - with `amount` 0 it is independent of time and phase, and non-zero at `u` = 0.5 (the still pose is not flat)
  - periodic in `FLUTTER_PERIOD_S`
  - phases 0 and 0.37 differ at the same time
  - never changes by more than 0.04 at `u` = 1 between ticks 0.08 s apart, so it never flaps
  - anchor: `flutterOffset(0, 0, 1, 0)` ≈ 0 and `flutterOffset(FLUTTER_PERIOD_S / 4, 0, 1, 1)` ≈ `FLUTTER_AMPLITUDE · sin(π/2 − 2π)`
